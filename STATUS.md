# What is current and what is history

Updated 2026-10-17. Everything in the repo root except `archive/` is part of
the current system or its evaluation. `archive/` holds history: research
notes, superseded designs and raw copies of experiment workspaces. Nothing was
deleted when the repo was split; files were moved with `git mv`.

### `validation/`

- `validation/validation-evidence/harness/score.py`, `score_utils.py`, `gt.py`,
  `split.py`: the scorer that `eval/run_eval.py` runs, and the scripts that
  build its ground truth and dev/lockbox split. These are current.
- `validation/validation-private/gt.json`, `split.json`: what the scorer
  compares against. `gt.json` is generated by `gt.py`; do not edit it by hand.
- The other harness scripts (`f1_rules.py`, `f3_discovery.py`,
  `f4_cascade.py`, `f2_probe.py`, `verify_windows.py`, ...) and `logs/` are the
  experiments behind A00 and A04-A09. Kept here, not in `archive/`, because
  they share the scorer's paths.

### Labels: where the ground truth comes from

- Organizer labels: `open_labels.xlsx`, outside the repo
  (`datathon:~/data/open/open_labels.xlsx`). Verdict and one or more seconds
  per video. The only ground truth for verdict and timing.
- Team annotation: `data/Таблица_нарушений.xlsx`. Violation type and norm per
  event, used for the scorer's rule (norm-code) check; and violation/clean
  clip pairs, which `split.py` uses to keep a pair on the same side of the
  dev/lockbox split.
- `gt.py` reads both and writes `validation/validation-private/gt.json`.
- The service itself never reads labels (`tests/test_no_label_access.py`).

## History (`archive/`)

See `archive/README.md` for what each folder holds and which attempt it backs.

| Path | What it is |
|---|---|
| `archive/research1/` | Research phase notes: problem exploration, reframing, validation write-up, technology landscape, ADR-001 (superseded), ADR-002, architecture and implementation plan |
| `archive/docs-vlm-era/` | Versions of `docs/ARCHITECTURE_SUMMARY.md`, `docs/MODELS.md`, `docs/LIMITATIONS.md` and `tree.md` written when the VLM was planned as the main detector |
| `archive/vm-copies/` | Raw copies of the workspaces on the Brev VMs (kits, teammate apps, spike outputs). Source code and logs behind A01-A03, A10, A11, A13, and the saved states A09 re-scores |
| `archive/agents/`, `archive/skills/` | Agent prompts and research skills used during problem exploration |
| `archive/data-prepared-old/` | Structured copy of the team workbook from 17:55 (`events.jsonl`, schema, validation report). Its generator `prepare_data.py` is no longer in the repo |

Two current files still read from the archive, on purpose:

- `scripts/build_knowledge.py` reads the norm texts from
  `archive/vm-copies/datathon/forte_brev_kit/brev_kit/codex/codex_verified.json`.
- `tests/test_rules_equivalence.py` compares `backend/rules/timeline.py` with
  the kit's original `timeline_rules.py` on the kit's saved states.

## Paths moved on 2026-10-17

Logs written before the move (`*.log`, `*.txt`, `*.csv`, `*.json` in
`attempts/` and `validation/validation-evidence/logs/`) still show the old
paths. Map them with this table:

| Old path | New path |
|---|---|
| `reasearch1/validation-evidence/` | `validation/validation-evidence/` |
| `reasearch1/validation-private/` | `validation/validation-private/` |
| `reasearch1/*.md` | `archive/research1/*.md` |
| `reasearch2/` | `archive/vm-copies/` |
| `agents/`, `skills/` | `archive/agents/`, `archive/skills/` |
| `data/prepared/{README.md,events.jsonl,schema.json,validation_report.json}` | `archive/data-prepared-old/` |

The research harness takes its root as an argument: what used to be
`python -I .../gt.py reasearch1` is now `python -I .../gt.py validation`, and
`eval/run_eval.py --root` defaults to `validation`.
