# Forte cash-discipline video checker

A fully local AI service for Datathon 26: upload a short cashier-desk video
(`.mov`, `.mp4` or `.mkv`), get back a verdict - **«Нарушение не обнаружено»** (no violation)
or **«Обнаружены признаки возможных нарушений»** (signs of possible
violations) - with, for each finding, a timecode, 1–3 evidence frames, a
plain-language description and a link to the normative source.

No cloud AI is used anywhere in the processing path (task.md §7). Everything
- perception, rules, evidence extraction, serving - runs on the team's own
GPU host.

## Repository layout (high level)

What is current and what is history: [`STATUS.md`](STATUS.md). Full tree:
[`tree.md`](tree.md).

- `backend/` - FastAPI service, pipeline, F1 detector, rules, knowledge grounding (Python).
- `frontend/` - React + TypeScript UI.
- `realtime/` - live verdict gateway (WebSocket).
- `config/`, `knowledge/` - detector config, rule thresholds and the Knowledge Pack.
- `tests/`, `tests/e2e/` - unit/integration tests and the external acceptance suite.
- `eval/`, `validation/` - scoring of API outputs against the private ground truth.
- `attempts/` - every experiment with its result and logs.
- `robustness/` - the other-angle filming protocol and results.
- `archive/` - research notes, superseded designs, raw VM workspace copies.

See `AGENTS.md` for engineering guidelines and `docs/ARCHITECTURE_SUMMARY.md` for the current design.

## Local development

```bash
.venv/bin/python -m pytest tests
.venv/bin/ruff check backend

# frontend
cd frontend
npm install
npm test
npx tsc --noEmit
npm run build
```

## Privacy

Organizer dataset videos, frames and labels are never committed to this
repository (see `.gitignore`) and never leave the deployment host. Test
videos supplied by the jury are processed and discarded per `docs/LIMITATIONS.md`.
