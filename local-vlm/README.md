# local-vlm — альтернативный локальный прототип (ноутбук, 6 ГБ GPU)

Отдельная ветка с прототипом, который целиком работает на ноутбуке (RTX 4050 Laptop, 6 ГБ видеопамяти):
веб-интерфейс + API по ТЗ, трасса каждой обработки, подбор правил на датасете. Это не замена `backend/`,
а площадка для сравнения подходов: удачные идеи можно переносить в основной сервис.

## Что внутри

| Папка | Что |
|---|---|
| `prototype/` | Сервис: FastAPI (`app.py`), конвейер (`pipeline.py`), детектор людей (`people.py`), действия кассира 8B (`actions.py`), трасса (`run_trace.py`, `static/trace.html`), пакетная оценка (`batch_eval.py`), эксперименты (`tools/`). Подробно — [`prototype/README.md`](prototype/README.md) |
| `brev_kit/` | Анкета состояний (схема, промпты `prompts_v2` / `prompts_fast`), правила по таймлайну (`scripts/timeline_rules.py`), увеличенные проверки (`scripts/zoom_checks.py`), оценка (`scripts/eval_*.py`), кодекс норм (`codex/codex_verified.json`) |
| `research/` | Кодекс норм РК (217 пунктов, `codex/`, `Кодекс_норм.xlsx`), тексты актов с якорями пунктов (`acts/`), разбор нормативной базы и датасета |

## Как это работает (v3/v4)

1. Кадры 2 fps → **анкета состояния кадра** Qwen3-VL 4B (Ollama, 17 полей) с шагом 1,5 с; неизменившиеся кадры не отправляются.
2. **Детектор людей D-FINE-S** (Apache-2.0, ~8 мс/кадр) на всех кадрах: люди в комнате (люди за стеклом отсекаются по линии пола), кто стоит.
3. **Проверки крупным планом** (~1 с): модель находит рамки стола/сейфа/ноутбука/двери, дальше узкие вопросы по кропу — деньги и сумка на столе, сейф, экран, дверь.
4. **Правила по таймлайну** → нарушение + таймкод → пункт нормы по ID из кодекса (без генерации текста норм).
5. **v4:** окна действий из 4 кадров для Qwen3-VL **8B** только в моменты событий (уход клиента, сессия, кассир с деньгами) — пересчёт без клиента, пересчёт без детектора. На 6 ГБ 8B частично в ОЗУ: ~5 с на окно.
6. **Трасса** каждой обработки: шаги и время, кадр с рамками объектов и людей, матрица состояний, кропы с ответами, кадры-доказательства.

## Что сюда НЕ попало (правила репозитория и данных хакатона)

Видео, кадры организаторов, трассы, таблицы со встроенными кадрами, разметка по роликам (`brev_kit/data/*.csv`)
и результаты прогонов по роликам — остаются локально. Для оценки положите свои `gt_violations.csv`, `videos.csv`,
`gold_states.csv` в `brev_kit/data/`, видео — в `open/open/videos/` (относительно `local-vlm/..`) или укажите `--videos`.

## Быстрый старт

```bash
pip install -r prototype/requirements.txt -r prototype/requirements-detector.txt
ollama pull qwen3-vl:4b-instruct          # анкета и кропы
ollama pull qwen3-vl:8b-instruct          # окна действий (можно выключить: ACTION_MODEL=)
python -m uvicorn --app-dir prototype app:app --host 127.0.0.1 --port 8080
```

Нужен тег `-instruct`: теги без него — «думающие» версии, возвращают пустой ответ.
